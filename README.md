# school-schedule（行事予定管理アプリ・試作）

学校ごとに異なる行事予定表の形式に対応する、定義駆動の汎用行事予定管理アプリの試作です。
学校が項目・対象軸・記号の凡例・当番・ビュー（表示と公開範囲）を定義として持ち、コード変更なしに自校の形式へ合わせる設計になっています。

## 実装されているもの（試作）

- 表示スタイル：L1 月・縦表／L2 週・縦表（1・2週間）／L3 年間横連結（4月〜3月）／L4 カレンダー格子／L5 週タイムライン（時刻軸・時限軸）／L6 転置表
- セル直接入力 → Enter で予定オブジェクト化、クイック入力カード（担当者→場所→時間の段階式。休暇は取得者→休暇分類→時間）
- 対象別の同値グループ化表示（例：下校時刻が全学年同じなら「1～6年 14:30～14:40」）
- ドラッグ＆ドロップで予定を別の日へ移動
- 当番の輪番自動生成・交換／代行・出張／休暇との競合検出と交代候補の提示
- プリセット（小学校バスなし／バスあり／中学校）、項目定義・対象軸・ビュー構成などの設定編集
- 集計（授業日数・給食日数などを凡例から導出）、公開範囲で絞る生徒用ビュー
- ビュー定義からの印刷／PDF（版ラベル・発行履歴つき）
